# Portland Budget Treemap

Interactive views of the City of Portland's FY 2026-27 budget, published by the City Budget Office.

**Live site:** https://pdxbudget.github.io/Budget/

| Page | Path | What it is |
|---|---|---|
| Adopted budget treemap | `/` | FY 2026-27 Adopted Budget by service area, bureau, program and fund |
| Treemap with decision packages (mockup) | `/treemap-dp/` | The same treemap with FY 2026-27 Fall Supplemental decision packages (DPs) merged in |

---

## Adopted budget treemap

- **Levels:** City (bureaus grouped by service area) → service area → bureau. At the bureau level, switch between a breakdown by program or by fund. Select a program to break it down by sub-program, and select any sub-program or fund to see its funding sources and spending categories.
- **Funds:** All funds, or the General Fund (Fund 100) only.
- **Budget measure:**
  - **Total budget** ($8.55B): the legal budget under Oregon Local Budget Law, including fund-level requirements such as contingency, debt service, transfers, reserves and ending fund balance.
  - **Capital** ($1.19B): spending on Capital Improvement Plan projects.
  - **Operating** ($7.35B): everything else.

Totals tie to the FY 2026-27 Adopted Budget: Table 1 for all funds ($8,546,060,062), Figure 10 for the General Fund ($1,186,002,037), and Table 10 for the operating/capital split. Prosper Portland shows only its City-budgeted amount.

## Treemap with decision packages (mockup)

- **Decision packages toggle:** *Base budget* (adopted only), *All DPs* (adopted plus every request; tiles show the percentage change), and *DPs only* (just the requested change; tile size is the size of the change and striped tiles are net decreases).
- **Service impact toggle:** *All requests*, *Service impact* or *No service impact* limits which DPs are counted. Turned off while *Base budget* is selected.
- **Program narrative:** opening a program shows its description from the adopted budget book. Selecting a sub-program shows its full description and services.
- **Commitment items:** every spending category expands to its commitment items in the side panel, the DP tables and the DP pages.
- **Decision package pages:** each request has its own page (`treemap-dp/#dp-<id>`) with its full amount across every program and sub-program, spending categories, resources and requirements by fund, and positions.
- **Decision packages at every level:** below the treemap, requests are listed for the level you're on and follow every toggle.

Totals tie to the adopted budget ($8,546,060,062; General Fund $1,186,002,037) and the requested changes ($530,518,741; General Fund $42,711,774). DP position costs are added to Personnel as operating spending; DP lines count as capital when their project is a CIP project.

**Sample data:** service impact flags and impact type tags are not yet collected in BFM. They are sample values assigned in `build/prep.py` from each package's request type, amount and service impact text. Dollar amounts, FTE, package text and program descriptions are real. When bureaus start entering real tags, replace the sample tagging block in `prep.py` with the new BFM fields.

## Sources

- **Adopted budget:** Ad Hoc Reporting Tool export, FY 2026-27 Adopted Budget (expense requirements). Embedded in `index.html`.
- **Requests:** BFM Fall TAO – D7 – DP Data Export (financial and personnel exports): 3,736 line items, 271 packages. The financial export leaves out personnel costs generated by positions, so the $7,417,520 in position costs from the personnel export is added to Personnel requirements, assigned to programs by each position's functional area.
- **Program descriptions:** FY 2026-27 Adopted Budget book on OpenBook (portland.openbook.questica.com), saved in `build/program_descriptions.json`.

## Rebuild the DP treemap

Requires Python 3 with `pandas` and `openpyxl`. Run from the repo root:

```
python3 build/prep.py <DP export.xlsx> build/bureau_sa.csv dp.json
python3 build/prep_programs.py <DP export.xlsx> <Ad Hoc.xlsx> build/bureau_sa.csv dp.json build/program_descriptions.json prog.json
python3 treemap-dp/build/prep_treemap.py index.html <DP export.xlsx> <Ad Hoc.xlsx> prog.json tmdp.json
python3 build/build.py treemap-dp/build/template.html tmdp.json treemap-dp/index.html
```

The intermediate `.json` files don't need to be committed.
